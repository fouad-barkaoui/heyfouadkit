# Name font

The name on the About the Founder page is designed for **PP Neue Machina,
Ultrabold** (Pangram Pangram). It is a commercial font, so it is not bundled.

If you have a licence, put the web font file here as
`neue-machina-ultrabold.woff2` (or `.woff`, `.otf`, `.ttf`). The page picks it
up at build time and uses it for the name. Until then the name uses
**Unbounded** (free, Google Fonts), the closest open alternative.
